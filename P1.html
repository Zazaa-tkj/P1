Belajar HTML

HTML (HyperText Markup Language) adalah bahasa dasar untuk membuat struktur halaman web.

1. Struktur Dasar HTML

<!DOCTYPE html>
<html>
  <head>
    <title>Judul Halaman</title>
  </head>
  <body>
    <h1>Hello World!</h1>
  </body>
</html>

2. Heading & Paragraf

<h1>Judul Utama</h1>
<h2>Sub Judul</h2>
<p>Ini adalah paragraf teks.</p>

3. Link & Gambar

<a href="https://www.google.com">Klik ke Google</a>
<img src="gambar.jpg" alt="Contoh Gambar" width="200">

4. Daftar (List)

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>Langkah 1</li>
  <li>Langkah 2</li>
</ol>

5. Tabel

<table border="1">
  <tr>
    <th>Nama</th>
    <th>Umur</th>
  </tr>
  <tr>
    <td>Andi</td>
    <td>20</td>
  </tr>
</table>

6. Formulir

<form>
  Nama: <input type="text"> <br>
  Email: <input type="email"> <br>
  Password: <input type="password"> <br>
  <input type="submit" value="Kirim">
</form>

7. Multimedia

<audio controls>
  <source src="lagu.mp3" type="audio/mpeg">
</audio>

<video width="320" height="240" controls>
  <source src="video.mp4" type="video/mp4">
</video>

8. Semantic HTML

<header>Bagian Header</header>
<nav>Menu Navigasi</nav>
<main>Isi Utama</main>
<footer>Bagian Footer</footer>

Belajar CSS

CSS digunakan untuk memberi gaya pada halaman HTML.

1. Cara Menyisipkan CSS

<style>
  body {
    background-color: lightblue;
  }
</style>

<link rel="stylesheet" href="style.css">

2. Selector Dasar

p {
  color: red;
}

#judul {
  font-size: 24px;
}

.kotak {
  border: 1px solid black;
}

3. Warna & Background

body {
  background: #f4f4f9;
  color: #333;
}

h1 {
  background-color: navy;
  color: white;
}

4. Font & Teks

p {
  font-family: Arial, sans-serif;
  font-size: 16px;
  text-align: justify;
}

5. Box Model

div {
  margin: 20px;
  padding: 15px;
  border: 2px solid black;
}

6. Flexbox

.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

7. Grid

.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 10px;
}

8. Animasi

@keyframes gerak {
  0% {background-color: red;}
  100% {background-color: blue;}
}

.box {
  width: 100px;
  height: 100px;
  animation: gerak 3s infinite;
}

Belajar JavaScript

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web interaktif.

1. Cara Menyisipkan JavaScript

<script>
  // Kode JavaScript di sini
</script>

<script src="script.js"></script>

2. Variabel dan Tipe Data

let nama = "Budi"; // String
const umur = 20; // Number
let isStudent = true; // Boolean
let hobbies = ["membaca", "coding", "olahraga"]; // Array
let person = {nama: "Andi", umur: 25}; // Object

3. Operator

let a = 10;
let b = 5;

console.log(a + b); // 15
console.log(a - b); // 5
console.log(a * b); // 50
console.log(a / b); // 2
console.log(a % b); // 0

4. Kondisional (If-Else)

let nilai = 85;

if (nilai >= 90) {
  console.log("Grade A");
} else if (nilai >= 80) {
  console.log("Grade B");
} else if (nilai >= 70) {
  console.log("Grade C");
} else {
  console.log("Grade D");
}

5. Perulangan (Loop)

// For loop
for (let i = 1; i <= 5; i++) {
  console.log("Iterasi ke-" + i);
}

// While loop
let count = 1;
while (count <= 3) {
  console.log("Count: " + count);
  count++;
}

6. Fungsi

// Fungsi biasa
function sapa(nama) {
  return "Halo, " + nama + "!";
}

// Arrow function (ES6)
const tambah = (a, b) => a + b;

console.log(sapa("Dian"));
console.log(tambah(5, 3));

7. Manipulasi DOM

// Mengambil elemen
let judul = document.getElementById("judul");

// Mengubah konten
judul.innerHTML = "Judul Baru";

// Mengubah style
judul.style.color = "blue";

// Menambahkan event listener
judul.addEventListener("click", function() {
  alert("Judul diklik!");
});

Belajar Python

Python adalah bahasa pemrograman tingkat tinggi yang mudah dipahami dan serbaguna.

1. Variabel dan Tipe Data

nama = "Budi"  # String
umur = 20     # Integer
tinggi = 170.5 # Float
is_student = True  # Boolean
hobi = ["membaca", "coding", "olahraga"]  # List
orang = {"nama": "Andi", "umur": 25}  # Dictionary

2. Operator

a = 10
b = 5

print(a + b)  # 15
print(a - b)  # 5
print(a * b)  # 50
print(a / b)  # 2.0
print(a % b)  # 0

3. Input dan Output

nama = input("Masukkan nama Anda: ")
print("Halo, " + nama + "!")

4. Kondisional (If-Else)

nilai = 85

if nilai >= 90:
    print("Grade A")
elif nilai >= 80:
    print("Grade B")
elif nilai >= 70:
    print("Grade C")
else:
    print("Grade D")

5. Perulangan (Loop)

# For loop
for i in range(1, 6):
    print("Iterasi ke-", i)

# While loop
count = 1
while count <= 3:
    print("Count:", count)
    count += 1

6. Fungsi

def sapa(nama):
    return "Halo, " + nama + "!"

def tambah(a, b):
    return a + b

print(sapa("Dian"))
print(tambah(5, 3))

7. List dan Dictionary

# List
buah = ["apel", "jeruk", "mangga"]
buah.append("pisang")
print(buah[0])  # apel

# Dictionary
mahasiswa = {"nama": "Rina", "umur": 22, "jurusan": "Informatika"}
print(mahasiswa["nama"])  # Rina

8. Exception Handling

try:
    angka = int(input("Masukkan angka: "))
    hasil = 10 / angka
    print("Hasil:", hasil)
except ZeroDivisionError:
    print("Tidak bisa membagi dengan nol!")
except ValueError:
    print("Input harus berupa angka!")
